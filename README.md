# Почему уходят новые сотрудники

**Демо:** https://why-they-leave.vercel.app

Каждый третий из уволившихся не доработал и трёх месяцев. Сервис помогает HR понять, где и почему это происходит,
и вовремя заметить тех, кто собирается уйти, пока их ещё можно удержать.

## Как это работает

1. HR создаёт задачу приёма в Битрикс24, как обычно.
2. Система сразу планирует короткие опросы на 7, 14, 30 и 60 день.
3. В день срока HR отправляет сотруднику ссылку, тот отвечает без входа в систему.
4. Тревожный ответ с согласием на связь превращается в задачу для HR «к кому идти сейчас» с подсказкой, что делать.
5. При увольнении со стажем меньше 90 дней — опрос «почему уходите» и «остались бы, если…».
6. Все ответы складываются в сводку «где и почему уходят»: по точкам, отделам и руководителям.

## Как проверить

Пример сценария есть на главной странице демо. Кнопки «+7 дней» и «+60 дней» вверху перематывают время,
«↺ Сегодня» возвращает исходные данные. Все люди и данные вымышленные и хранятся только в вашем браузере.

## Что настоящее, а что имитация

- **Работает:** планирование опросов, обе формы опроса, флаги для HR, определение причин, сводка.
- **Имитация:** Битрикс24 (задачи создаются в самом приложении), отправка сообщений (HR копирует текст сам),
  хранение (localStorage вместо базы).
- **Причины из свободного текста** определяются по ключевым словам.

## Следующие шаги

- Интеграция с Битрикс24 по API: задачи и подзадачи создаются в настоящем портале.
- Telegram-бот, который сам отправляет опросы в день срока.
- ИИ для причин, которые не распознались по ключевым словам. В коде уже заложено, включается ключом API.
- База данных вместо хранения в браузере, вход для HR и директора.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Нужен Node.js 20+.

Стек: Next.js, TypeScript.
